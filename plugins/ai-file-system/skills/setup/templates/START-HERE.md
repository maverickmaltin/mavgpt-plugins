# Start here

This is [NAME] OS, your AI file system. It's a normal folder of plain-text notes that Claude and Codex read before they help you, so they already know who you are, what you're working on and how you like things done.

## How to use it every day

- **Claude desktop app:** start a chat, choose this folder from the message box, and just say what you need.
- **Claude Code / the Code tab:** open this folder. Claude reads CLAUDE.md automatically.
- **Codex:** open this folder as the project. Codex reads AGENTS.md automatically.

You don't need to manage the files. At the end of every task the AI saves what it learned to the right place.

## Handy phrases

- "Remember this: ..." saves a fact or preference where it belongs.
- "Add a workspace for [AREA]" sets up a new area.
- "Tidy my file system" cleans things up (do it once a month).
- "What's on my plate?" reads CURRENT.md and every workspace and tells you.
